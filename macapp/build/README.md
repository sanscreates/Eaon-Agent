# Eaon Agent — build artifacts

This directory holds generated build output. It is **not committed** — regenerate
these on demand; CI and the release pipeline rebuild them.

- `icon.png`  — 1024×1024 master app icon, generated by `node macapp/scripts/gen-icon.mjs` (dependency-free; runs anywhere with Node ≥ 18).
- `icon.icns` — macOS iconset, packed by `bash macapp/scripts/make-icns.sh` (macOS only, needs `sips` + `iconutil`; regenerates the PNG if missing).
- `icon.iconset/` — temporary 10-size iconset, deleted automatically after packing.
- `Eaon-*.dmg` — release disk images produced by `npm run dist` (see `macapp/package.json`).

Regenerate the icon from the repo root:

```bash
node macapp/scripts/gen-icon.mjs     # writes macapp/build/icon.png
bash macapp/scripts/make-icns.sh     # writes macapp/build/icon.icns
```
